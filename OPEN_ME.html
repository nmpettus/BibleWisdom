⚠️ You're in a Remote Environment
Since you're using Claude Code in a browser, you can't access localhost directly. Follow the instructions below to access your app.

Option 1: Use GitHub (Recommended)

Step 1: Your code is already pushed to GitHub branch:
claude/health-timeline-setup-y2yri
Step 2: Clone the repository to your local computer:
git clone https://github.com/nmpettus/BibleWisdom.git
Step 3: Switch to the branch:
git checkout claude/health-timeline-setup-y2yri
Step 4: Install and run:
npm install
npm run dev
Step 5: Open in your browser:
http://localhost:5173

Option 2: Deploy to GitHub Pages

Go back to Claude Code and ask me to:
"Deploy the Health Timeline app to GitHub Pages"

This will give you a public URL like:
https://nmpettus.github.io/BibleWisdom/

Option 3: Download the Build

Step 1: Download the entire dist folder from the repository
Step 2: Run a local server in that folder:
npx serve dist
or
python -m http.server 8000 (in the dist folder)
